SONAR EDGE XL - iCUE setup

1. Extract the entire ZIP and open SonarEdge.exe.
2. Tap the bottom gear for Settings > App version. Use Find XL widget to
   locate the importable widget file. Keep Sonar Edge running.
3. In iCUE, open XENEON EDGE > Screen Setup. Set Display Mode to iCUE Widgets,
   then open Widgets.
4. Use the widget import (+) button and choose Sonar Edge XL.icuewidget.
   If iCUE asks to allow access to localhost:47832, click Allow. That is the
   Sonar Edge running on your own PC; it supplies Sonar and music controls.
5. Add Sonar Edge XL to an empty page/slot.
6. Select the widget, open Appearance, and set Size to XL.

Sonar Edge XL is a native entry in iCUE's widget library after importing the
package. Select it there to add it; no iframe HTML or URL entry is needed.
To start Sonar Edge automatically at sign-in, open Settings > App version,
choose iCUE iframe as the default, check Start with Windows, then Save changes.
Enable iCUE's own Windows startup setting as well.

XL fills the iCUE dashboard area. On a horizontal XENEON EDGE, iCUE reserves
its own 12-pixel border, leaving a 2536 x 696 content area. Sonar Edge fills
that area with no additional iframe border, margins, or scrollbars.
The size is chosen in iCUE; an iframe cannot resize its enclosing widget.

The current package enables touch and mouse input on XENEON EDGE. If you
imported an older package that displays controls but ignores input, import
the current Sonar Edge XL.icuewidget to update the widget stored by iCUE.
Updating the app alone does not update iCUE's imported widget manifest.

Keep Sonar Edge running to control Sonar and your music player. One app and
one tray icon serve both the desktop window and the iCUE widget.
Minimizing or closing the window hides it from the taskbar; iCUE keeps working.
Double-click the tray icon, or choose Open Sonar Edge, to restore the window.
Choose Exit Sonar Edge from the tray menu to quit the whole app.
The bottom gear opens Settings. Window & display contains fullscreen and
monitor placement controls. Both views share layouts, backgrounds and audio
controls in LocalAppData\SonarEdge.

Each person installing Sonar Edge controls only their own PC. The local iCUE
connection needs no address entry or external hosting.

Optional: the exact HTML for iCUE's built-in iFrame widget is:
<iframe src="http://127.0.0.1:47832/embed" title="Sonar Edge" style="position:fixed;inset:0;width:100%;height:100%;border:0;margin:0;" allow="fullscreen"></iframe>

The importable widget already contains this, so pasting HTML is not needed.
